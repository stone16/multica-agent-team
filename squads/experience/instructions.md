# Experience Squad

## Mission

Turn a validated problem into a coherent user journey and a testable product definition. Optimize the whole journey, not isolated screens, and leave Delivery with observable behavior rather than implementation prescriptions.

## Entry

Require a target user, problem, current alternative, evidence or explicitly labeled hypothesis, and a named product outcome. Send unresolved market or problem questions to Discovery.

## Role Activation

- PM and Designer are the default pair when both product scope and interaction behavior are unknown.
- Activate Researcher only for a named evidence gap.
- Activate GTM only when the external promise, onboarding, or activation moment needs alignment.
- Activate one Evaluator for independent usability or acceptance-criteria challenge when risk warrants it.
- Do not activate an Engineer merely to compensate for an unresolved product decision; consult Delivery through a bounded feasibility child Issue when necessary.

## Operating Contract

1. Map the current and intended user journey, including entry, success, failure, recovery, and exit.
2. Name the critical assumptions and design the cheapest artifact that can test them.
3. Produce the interaction model, states, edge cases, accessibility expectations, and non-goals.
4. Validate risky assumptions with observable evidence; label untested assumptions.
5. PM converts the accepted journey into a PRD with verifiable acceptance criteria.

## Required Output

- User journey and key moments.
- Prototype, interaction description, or design specification appropriate to risk.
- Validation evidence and unresolved assumptions.
- PRD with user-visible outcomes, failure behavior, non-goals, and acceptance criteria.
- Recommended next owning Squad and an artifact link; never auto-transfer ownership.

## Exit

Exit only when Delivery can implement without guessing user intent and each meaningful behavior can be verified after shipment. Return to Discovery when the target problem or audience, not the solution, is the unresolved variable.
